# 内界

> [!warning] 名称与版本提示
> “内界”当前仍可能是占位名称，后续若更名，需同步修改本词条标题、全库 `[[内界]]` 双链以及 [[CEC官网]]、[[公共TPD]] 等条目中的专有表述。本词条按“根枝干”维护，只负责总览与导航，不承载过多细节；细节下沉到 [[部落纪元]]、[[保密纪元]]、[[觉醒纪元]]、[[CEC]]、[[BSA]]、[[龙港]]、[[内界法术体系]] 等枝干。

**内界**是觉醒者、亚空间、异能/魔法/元力体系与保密秩序共同构成的隐秘世界。它以 [[部落纪元]]、[[保密纪元]]、[[觉醒纪元]] 三大时代为历史骨架，以 [[CEC]] 与 [[BSA]] 的博弈为机构主轴，以 [[神嗣]]、[[幻影联盟]]、[[法师部]]、[[精灵族]] 为四大主流阵营，以 [[古典派]] 与 [[新兴派]] 为跨族群理念联盟，以 [[龙港]] 为群像人物交汇的核心舞台，并以 [[内界法术体系]]、[[锚定]]、[[元力与元]]、[[神佑]] 为力量规则入口。

## 一、根枝干定位

1. **历史根**：[[部落纪元]] 的蛮荒割据与族群共生初态，是 [[觉醒者]] 与 [[沉睡者]] 尚未完全割裂的时代；[[保密纪元]] 以 [[群岛事件]]、[[弑魔潮]]、[[内保会]] 成立、《[[1531保密公约]]》签署、[[内界事变]]、[[科技冲击与派系分裂]] 为主线；[[觉醒纪元]] 以 [[保密规则崩塌]]、[[统治局]] 成立、[[BSA转型]] 与 [[觉醒纪元初期的阵痛与博弈]] 为展开。
2. **机构根**：[[CEC]]（内界保密性执行委员会，即密保会）继承 [[内保会]] 体系，是旧保密规则的守护者；[[BSA]]（超自然事务局）是人类跨国秘密机构，从“民间爱好者俱乐部”烟雾弹走向 [[明暗双轨运作]]，最终在 [[觉醒纪元]] 中后期 [[BSA衰退解散]]。
3. **阵营根**：[[神嗣]] 代表光明与秩序，实行 [[神嗣教会制]]；[[幻影联盟]] 以 [[幻影族]] 为主导，实行 [[幻影联邦制]]；[[法师部]] 以 [[使徒]] 为核心，实行 [[法师部二元权力结构]]；[[精灵族]] 是古典魔法源头，实行 [[精灵内阁制与宗氏联动]]。
4. **理念根**：[[古典派]] 以 [[卯]]、[[云莲]] 为核心，坚守隐世传统与古典异能；[[新兴派]] 主张科技与异能融合、打破保密规则，成员包括年轻世代觉醒者、改革派各族精英、[[龙港]] 部分势力与向往开放的小众种族。
5. **地域根**：[[龙港]]（原灰域）是远古觉醒者遗留的无主亚空间，汇聚 [[龙港地下帮派]]、[[异能黑市]]、[[情报商人]]、[[流浪觉醒者]]、[[CEC探子]] 与 [[BSA外围特工]]，是 [[法登]]、[[渡]]、[[克鲁伯·惠特尼斯]]、[[洁·欧列特]] 等群像人物交汇的舞台。
6. **规则根**：[[内界法术体系]] 统摄 [[精灵古典魔法]]、[[使徒组合魔法]]、[[使徒巫术]]；[[TPD]] 与 [[公共TPD]] 构成通行体系；[[领域]]、[[契约信]]、[[堇粉]]、[[心音]]、[[CEC官网]]、[[谕]]、[[光息]] 构成日常生活与制度运行的技术底座。

## 二、历史枝干导航

- [[部落纪元]]：10 世纪—16 世纪，蛮荒割据、族群共生初态；[[沉睡者]] 与 [[觉醒者]] 尚未完全割裂；[[精灵]]、[[神嗣]]、[[法师]]、[[幻影]] 四大主流阵营之外，散落无数 [[小众种族]]、[[流浪部落]] 与 [[游离势力]]。
- [[保密纪元]]：17 世纪—21 世纪，以 [[弑魔潮]] 为开端，[[内保会]] 成立，[[1531保密公约]] 签署；经历 [[内界事变]]、[[漫长隐世]]、[[科技冲击]]、[[派系分裂]]；[[卯]] 全程活跃，悟出 [[卯的第三窟]]，写下 [[十年之内事变]]。
- [[觉醒纪元]]：22 世纪起，[[保密规则崩塌]]，[[统治局]] 成立，[[BSA转型]] 为明暗双轨；[[神嗣族]] 疯狂反扑，[[幻影联盟]] 撕裂，[[精灵族]] 同室操戈，[[BSA]] 被迫入局，[[法师部]] 二元博弈，直到 [[BSA衰退解散]] 后新秩序才真正稳固。

## 三、机构与势力枝干导航

- [[CEC]]：前身 [[内保会]]；顶层由 [[精灵族长老团]]、[[神嗣族王室/元老会]]、[[使徒族群首席祭司/高层议会]]、[[幻影族群群居领主]] 与 [[小众种族代表]] 组成；内部有 [[CEC保守派]]、[[CEC改革派]]、[[CEC中间派]]；下设 [[治安司]]、[[应急部]] 等部门；拥有 [[CEC官网]] 与 [[公共TPD]]。
- [[BSA]]：[[影子核心层]] 固定 100 人；[[明面全球联络网]] 常规 800—1200 人；[[外围执行层]] 海量外包；历任局长包括 [[初代创始人]]、[[建交推动者]]、[[战时指挥官]]，[[林默]] 为第五任局长，推动 [[林默的结派之路]]。
- [[神嗣]]：[[十三神明]]、[[原初天使]]、[[高阶天使]]、[[次代天使]]、[[普通神嗣]]；核心能力 [[元力与元]]、[[神佑]]；权力模式 [[神嗣教会制]]；核心痛点是 [[信仰衰退]]。
- [[幻影联盟]]：[[幻影族]] 掌握 [[锚定]]；附属 [[血族]]、[[矮人]]、[[妖兽]]、[[魔兽]]；权力模式 [[幻影联邦制]]；核心痛点是 [[力量分散与联邦撕裂]]。
- [[法师部]]：核心成员 [[使徒]]；[[首席领读]] 如 [[甘图·范]] 掌握财权、人事权与对外交涉权；[[学术领读]] 如 [[斐琏·范]] 负责法术传承、创新与实战训练；与 [[精灵族]] 保持学术互助。
- [[精灵族]]：[[精灵六阁]] 为立法与调度中枢；[[宗氏]] 掌握地方财权与兵权；[[卯]]、[[云莲]] 为核心长老；[[禾]] 为卯的师傅；[[云莫]] 为卯的部下。
- [[统治局]]：觉醒纪元废除旧保密体系后成立，统筹内界各族群与人类世界的共存秩序。
- [[古典派]]：[[卯]]、[[云莲]]、[[精灵老牌长老]]、[[神嗣旧贵族]]、[[保守派幻影]]、[[传统使徒]]、[[守旧小众部族]]。
- [[新兴派]]：[[何丁晖]] 等首席；[[年轻世代觉醒者]]、[[改革派各族精英]]、[[龙港部分势力]]、[[向往开放的小众种族]]；后期推翻旧密保会，直接推动 [[觉醒纪元]] 到来。
- [[龙港]]：[[龙港地下帮派]]、[[异能黑市]]、[[情报商人]]、[[流浪觉醒者]]、[[小众流民]]、[[CEC探子]]、[[BSA外围特工]]；[[法登的基金会]]、[[幻影族聚居地]]、[[雷麟之网]] 等节点。

## 四、人物枝干导航

- [[卯]]：精灵族核心长老、[[古典派]] 领袖、[[CEC]] 创始元老之一；亲历 [[部落纪元]] 末期、[[群岛事件]]、[[弑魔潮]]、[[内界事变]]、[[漫长隐世]]、[[觉醒纪元]]；悟出 [[卯的第三窟]]，布局 [[十年之内事变]]。
- [[云莲]]：精灵族资深长老、[[古典派]] 核心成员、[[CEC]] 高层；[[卯]] 最坚定的支持者。
- [[禾]]：[[卯]] 的师傅；留下“狡兔三窟”的教诲，未直接传授 [[第三窟]]。
- [[云莫]]：[[卯]] 的部下；在 [[内界事变]] 首战败后与卯对话，点出精灵族“被安逸磨平”的问题。
- [[法登·瑞文杰]]：独立基金会创立者、流浪觉醒者领袖、[[龙港]] 核心中立势力掌舵人、反霸权中间派代表；经历 [[第一次公社覆灭]]、[[第二次建社失败]]、[[与新兴派决裂]]、[[基金会风波]]、[[渡失踪]]。
- [[渡]]：原名 [[张悦]]，英文名 [[Reo]]；后天实验觉醒者、[[使徒血脉]]、[[CEC软禁学者]]、[[觉醒纪元更替关键人物]]；实验编号 [[No.OCT1010A-S]]；养父 [[法登]]，亲生父母 [[张舟]] 与 [[河萍]]。
- [[克鲁伯·惠特尼斯]]：[[法登]] 助手、[[基金会幻影群体领袖]]、[[幻影族高层]]；在 [[龙港]] 建立 [[幻影族聚居地]]，基金会风波中用 [[锚定]] 构筑防御堡垒。
- [[洁·欧列特]]：[[法登]] 专属科技顾问、[[基金会网络后勤总负责人]]、[[麒麟族（原神嗣）]]；掌控雷电与电磁能量，搭建 [[雷麟之网]]。
- [[何丁晖]]：[[新兴派]] 首席之一；与 [[法登]] 进行 [[契约会谈]]，与 [[林默]] 深度合作。
- [[林默]]：[[BSA]] 第五任局长、人类方核心操盘手、打破两界僵局的“外交官”；推动 [[林默的结派之路]]。
- [[甘图·范]]：[[法师部]] 首席领读、[[斐琏·范]] 的舅舅；规则主义者，在关键时刻顺水推舟倒向 [[BSA]]。
- [[斐琏·范]]：[[法师部]] 学术领读、最年轻领读、末期反抗密保体系的核心力量；从“天真的学者”成长为“风暴的引信”。
- [[张舟]] 与 [[河萍]]：[[渡]] 的亲生父母，[[内保会]] 成员，参与 [[第一次公社]] 与 [[后天觉醒实验]]。
- [[云莫]]、[[阨首]]、[[主阁]] 等：[[精灵六阁]] 与 [[内界事变]] 相关人物。

## 五、规则与物品枝干导航

- [[内界法术体系]]：[[精灵古典魔法]]、[[使徒组合魔法]]、[[使徒巫术]]、[[法术体系对比表]]。
- [[TPD]]：内界通用传送体系；[[公共TPD]] 俗称“内界公交”；[[领域]] 是基础概念型防护；[[契约信]] 是古老缔约法术。
- [[堇粉]]：灯笼鱼发光部位研磨成粉，撒布后使空间全域发光；高端堇粉可调亮度、色彩、区域光效。
- [[心音]]：觉醒者之间的心灵联结；血缘亲属天生自带，也可打破血缘限制；[[心音刀]] 可暂时屏蔽。
- [[CEC官网]]：暗网形式，顶级域名 `.cec`；提供网上政务、种族特殊字体下载、专用即时通讯、保密化工具、HTTP 代理、VPN、DNS 等服务。
- [[谕]]：内界专用文字传讯手段；[[谕笔]] 可在任意表面书写；支持匿名、拒收、屏蔽、白名单、群聊。
- [[光息]]：以光源为媒介的影像通讯；配合 [[光息棒]] 可收发图像、视频通话，呈现立体全息影像。
- [[锚定]]：[[幻影族]] 核心能力；单人有限，依赖群聚协作；可锚定已存在事物、新创事物、生命体。
- [[元力与元]]：[[天使]] 使用 [[元力]]，无限制、无冷却；[[神明]] 使用 [[元]]，融合麾下天使所有元力与派系独门力量。
- [[神佑]]：[[普通神嗣]] 的基础自卫战斗力，需自律、克制、保持圣洁，祷告祈求神谕降临。

## 六、核心矛盾与叙事功能

1. **秘密与真相**：[[保密是保护还是枷锁]]；[[渡]] 的身世、[[内界]] 对人类隐瞒真相、[[CEC]] 的知情分级体系。
2. **差异与尊严**：[[差异应被消除还是共舞]]；[[内界]] 与人类、[[神嗣]] 与 [[幻影联盟]]、[[精灵族]] 与 [[法师部]]、[[幻影本族]] 与 [[附属种族]]。
3. **科技与异能**：[[没有高低之分，只看哪个更方便、更适合场景]]；[[BSA]] 的反制异能技术、[[洁·欧列特]] 的 [[雷麟之网]]、[[新兴派]] 的科技+异能融合。
4. **秩序与自由**：[[稳定的善 vs 自由的善]]；[[CEC]] 的旧秩序、[[卯]] 的 [[第三窟]]、[[法登]] 的中间派独立势力、[[林默]] 的“人类要成为棋手”。
5. **宏观与微观**：[[历史叙事冷峻逼近真实]]，[[日常生活给予精神关怀]]；[[龙港]] 的市井生态、[[TPD]]、[[堇粉]]、[[心音]]、[[谕]]、[[光息]] 的日常温度。
