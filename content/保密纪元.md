# 保密纪元

**保密纪元**是 [[内界]] 从 [[部落纪元]] 的蛮荒割据走向全面隐世、再走向保密崩塌的核心过渡阶段。它以 1521 年 [[群岛事件]] 为导火索，以 1525—1532 年 [[弑魔潮]] 为浩劫开端，以 1531 年 [[内保会]] 成立与《[[1531保密公约]]》签署为秩序起点，历经 [[1589—1596 内界事变]]、[[16—21世纪 漫长隐世]]、[[21世纪 科技冲击与派系分裂]]，最终在 21 世纪末因 [[新兴派]] 崛起与 [[BSA]] 反制技术成熟而 [[保密规则崩塌]]，进入 [[觉醒纪元]]。

## 一、纪元定位

1. **历史定位**：[[部落纪元]] 与 [[觉醒纪元]] 之间的核心过渡阶段；[[内界]] 与人类从偶尔混居、小规模摩擦，走向系统性保密与隐世隔绝。
2. **秩序定位**：[[内保会]]（后定名 [[CEC]]）诞生，[[1531保密公约]] 成为内界最高共识；[[不可显露于世]] 成为跨阵营铁律。
3. **博弈定位**：[[CEC]] 内部 [[保守派]]、[[改革派]]、[[中间派]] 博弈；[[古典派]] 与 [[新兴派]] 分裂；[[BSA]] 从隐蔽监控者转为 [[隐形棋手]]。
4. **人物定位**：[[卯]] 全程活跃，无失忆、无隐世；[[云莲]] 辅佐维系秩序；[[法登]]、[[渡]]、[[林默]]、[[何丁晖]]、[[斐琏·范]]、[[甘图·范]] 等成为纪元末期的关键变量。

## 二、时间枝干

### 1. 1521 年：导火索·[[群岛事件]]

[[麦哲伦船队]] 中的 [[使徒族群]] 成员，意外引发当地 [[土著族群]] 与 [[幻影族群]] 的三方激烈冲突。事件发酵后，[[觉醒者]] 的存在与异能力量逐渐暴露在欧洲人类视野中，直接埋下人类猎杀觉醒者的隐患。该事件连接 [[使徒]]、[[幻影族]]、[[人类]]、[[CEC前身]] 与 [[BSA前史]]。

### 2. 1525—1532 年：浩劫·[[弑魔潮]]

欧洲人类因恐惧异能力量，发起大规模猎杀行动，针对所有 [[内界觉醒者族群]] 展开无差别清剿。[[精灵族]]、[[神嗣族]]、[[使徒]]、[[幻影族]] 均遭重创，被迫彻底脱离人类社会，放弃与人类混居的生存模式。该事件是 [[内保会]] 成立与 [[1531保密公约]] 签署的直接背景，也是 [[卯]] 推动内界联合的核心动因。

### 3. 1531 年：秩序建立·[[内保会]] 诞生

为避免族群覆灭、统一应对人类威胁，[[内界四大主流阵营]] 联合 [[小众势力]]，成立 [[内保会]]（[[CEC]] 前身），召开 [[保密和会]]，正式签署《[[1531保密公约]]》。[[内界]] 自此进入全面隐世的保密时代，彻底与人类世界隔绝，隐藏所有异能痕迹。该事件连接 [[CEC]]、[[1531保密公约]]、[[不可显露于世]]、[[保密和会]]、[[四大主流阵营]]。

### 4. 1589—1596 年：内界制衡·[[内界事变]]

[[内界]] 内部因权力、生存理念分歧爆发内战，对战双方为 [[法师部+幻影同盟]] 与 [[精灵+神嗣同盟]]。[[精灵族]] 核心长老 [[卯]] 全程参战，成为战局关键人物。战后 [[卯]] 推动各方达成和解，形成阵营制衡格局：[[法师部]] 获得独立地位，[[幻影族群]] 受限群居，[[内界]] 内部秩序趋于稳定。该事件连接 [[精灵六阁]]、[[天阁会议]]、[[云莫]]、[[阨首]]、[[主阁]]、[[法师部独立]]、[[幻影群居限制]]。

### 5. 16—21 世纪：漫长隐世·[[时代变迁]]

[[内界]] 严格恪守 [[保密公约]]，在隐世空间中平稳发展。[[精灵族]] 全程活跃于 [[内界事务]]，[[卯]] 作为核心长老，持续见证并参与 [[内界秩序维护]]，从未隐世或消失。此期间人类世界历经 [[工业革命]]、[[多次世界大战]]、[[科技飞速崛起]]，[[内界]] 则在隐世中坚守传统异能体系，默默观察人类变化，双方互不干扰。该阶段连接 [[古典派]]、[[CEC保守派]]、[[精灵宗氏]]、[[神嗣旧贵族]]、[[传统使徒]]。

### 6. 21 世纪：格局动摇·[[科技冲击与派系分裂]]

人类科技实现突破性发展，[[普通人类]] 借助 [[高科技武器]]、[[科研技术]]，逐渐拥有了对抗 [[觉醒者异能]] 的能力，[[内界]] 赖以生存的保密根基被动摇。[[内界]] 内部因此分裂为两大派系：

- [[古典派]]：以 [[卯]]、[[云莲]] 为核心领袖，坚守《[[1531保密公约]]》，主张延续隐世传统，在 [[古典异能]]、[[魔法]] 基础上创新优化，专注 [[超常能力]] 的深度研究与日常运用，排斥与人类过度接触。
- [[新兴派]]：主张打破保密规则，推动 [[科技与异能融合]]，追求 [[觉醒者]] 在人类社会的合法地位与平等权利，组织严密、谋略清晰，深耕人类社会各领域，成为挑战传统秩序的新生力量。

同期，人类世界成立 [[BSA]]（跨国秘密联合机构），以“[[民间爱好者俱乐部]]”为烟雾弹，核心编制仅百人，采用 [[外包制]] 隐秘研究 [[觉醒者]]、研发 [[反制异能技术]]，成为人类对抗 [[内界]] 的核心力量。

### 7. 21 世纪末：纪元更迭·[[保密规则崩塌]]

[[新兴派]] 势力不断壮大，凭借 [[科技+异能]] 的融合优势，推翻坚守传统的 [[内保会]]，《[[1531保密公约]]》彻底失效，[[保密纪元]] 正式终结，[[觉醒纪元]] 拉开帷幕。该事件连接 [[统治局]] 成立、[[BSA转型]]、[[CEC转型]]、[[觉醒纪元初期的阵痛与博弈]]。

## 三、暗流枝干：[[卯的第三窟]] 与 [[十年之内事变]]

在保密纪元末期，[[CEC]] 高层并非人人都沉迷旧秩序。[[精灵长老卯]] 在亲眼见证 [[精灵族]] 因长期和平而“被安逸磨平”的现实后，悟出了师傅 [[禾]] 未曾传授的“[[第三窟]]”：

- **第一窟：防患于未然**。保持充足准备，永远有余地；对应 [[卯]] 在 [[内界事变]] 前对 [[法术护盾]]、[[保护性魔法]]、[[物理/精神/记忆保护法术]] 的重视。
- **第二窟：借力打力，出其不意**。利用敌人之力反制敌人；对应 [[禾]] 将 [[卯]] 的法术与咒语悉数奉还的 [[反弹施法]]。
- **第三窟：主动布局，万物为我所用**。在合适时机主动出击，占据主动位置；对应 [[卯]] 刻意放缓 [[CEC]] 对 [[法登]] 等“变量”的清剿，暗中放任 [[新兴派]] 与 [[BSA]] 接触，写下“[[十年之内事变]]”，将 [[法登]]、[[斐琏·范]]、[[何丁晖]]、[[林默]] 等棋子逐一安置于棋盘之上。

[[卯]] 不是时代被动的守护者，而是主动推倒旧秩序的“[[掘墓人]]”。她知道旧世界必须死，新世界才能生。该枝干连接 [[狡兔三窟]]、[[禾]]、[[卯]]、[[法登]]、[[斐琏·范]]、[[何丁晖]]、[[林默]]、[[新兴派]]、[[BSA]]、[[觉醒纪元]]。

## 四、机构与派系枝干

- [[CEC]]：继承 [[内保会]]—[[密保会]] 体系；顶层由 [[四大主流族群高层]] 与 [[老牌小众种族族长]] 组成；内部 [[保守派]]、[[改革派]]、[[中间派]]；[[卯]] 为主席，军权由会议调动，[[治安司]] 与 [[应急部]] 拥有代行权。
- [[BSA]]：创立前期秘密筹备；正式成立后伪装成 [[民间神秘爱好者俱乐部]]；[[百人核心制]] 与 [[外包挂靠]]；[[影子核心层]]、[[明面全球联络网]]、[[外围执行层]]；[[林默]] 推动 [[结派方针]]。
- [[古典派]]：[[卯]]、[[云莲]]、[[精灵老牌长老]]、[[神嗣旧贵族]]、[[保守派幻影]]、[[传统使徒]]、[[守旧小众部族]]。
- [[新兴派]]：[[何丁晖]]、[[年轻世代觉醒者]]、[[改革派各族精英]]、[[龙港部分势力]]、[[向往开放的小众种族]]；后期推翻 [[密保会]]。
- [[统治局]]：[[觉醒纪元]] 成立，统筹 [[内界各族群]] 与 [[人类世界]] 的共存秩序。
- [[法师部]]：[[甘图·范]] 与 [[斐琏·范]] 的 [[二元权力结构]]；末期与 [[BSA]] 结盟。
- [[精灵族]]：[[精灵六阁]] 与 [[宗氏]] 联动；[[卯]] 利用 [[内阁拖咨]] 与 [[程序正义]] 卡死战争机器；[[云莫]] 指出精灵族“被安逸磨平”。
- [[幻影联盟]]：[[幻影本族]] 渴望共居，[[附属种族]] 为自保可能倒向 [[CEC]] 或 [[BSA]]；[[克鲁伯·惠特尼斯]] 是 [[幻影族高层]] 与 [[基金会]] 核心。

## 五、关键人物枝干

- [[卯]]：[[精灵族核心长老]]、[[古典派领袖]]、[[CEC创始元老]]；亲历 [[群岛事件]]、[[弑魔潮]]、[[内界事变]]、[[漫长隐世]]、[[觉醒纪元]]；布局 [[十年之内事变]]。
- [[云莲]]：[[精灵族资深长老]]、[[古典派核心]]、[[CEC高层]]；[[卯]] 最坚定的支持者。
- [[禾]]：[[卯]] 的师傅；[[狡兔三窟]] 的传授者；未直接讲授 [[第三窟]]。
- [[云莫]]：[[卯]] 的部下；在 [[内界事变]] 首战败后点出 [[精灵族懈怠]] 与 [[中立换来的脆弱]]。
- [[法登·瑞文杰]]：[[独立基金会]] 创立者、[[流浪觉醒者领袖]]、[[龙港核心中立势力]] 掌舵人；被 [[卯]] 视为“变量”而刻意放缓清剿。
- [[渡]]：[[后天实验觉醒者]]、[[使徒血脉]]、[[CEC软禁学者]]、[[觉醒纪元更替关键人物]]；连接 [[法登]]、[[张舟]]、[[河萍]]、[[斐琏·范]]。
- [[林默]]：[[BSA第五任局长]]；推动 [[人类成为棋手]]；与 [[何丁晖]] 深度合作；隐约感觉 [[卯]] 在幕后操盘。
- [[何丁晖]]：[[新兴派首席]]；与 [[法登]] 进行 [[契约会谈]]；与 [[林默]] 结盟。
- [[斐琏·范]]：[[法师部学术领读]]；从 [[天真的学者]] 成长为 [[风暴的引信]]；与 [[渡]] 有深度学术交集。
- [[甘图·范]]：[[法师部首席领读]]；[[规则主义者]]；在 [[斐琏]] 造反时顺水推舟，成为倒向 [[BSA]] 的导火索。

## 六、规则与物品枝干

- [[1531保密公约]]：[[内界]] 最高共识；任何暴露 [[内界]] 存在的行为都会遭到所有阵营共同抵制；[[幻影族]] 曾反对该规则，后在 [[神明]] 高压下放弃。
- [[不可显露于世]]：跨阵营铁律；连接 [[CEC]]、[[神嗣]]、[[精灵族]]、[[法师部]]、[[幻影联盟]]。
- [[TPD]] 与 [[公共TPD]]：保密纪元通行体系；[[公共TPD]] 由 [[CEC]] 设立，伪装为电话亭、公厕门等公共设施，内设安检机制。
- [[领域]]：住宅、店铺、学校防护；房地产方附赠 [[领域搭建服务]]，防止 [[TPD]] 随意闯入。
- [[契约信]]：官方事务与 [[法律效力合同]]；[[法登]] 与 [[何丁晖]] 的 [[契约会谈]] 使用该体系。
- [[CEC官网]]：暗网 `.cec`；[[觉醒者]] 与 [[生命幻象]] 凭身份 ID 与密文登录；提供 [[网上政务]]、[[种族特殊字体下载]]、[[专用即时通讯]]、[[保密化工具]]。
- [[谕]] 与 [[光息]]：[[CEC]] 常用 [[谕]] 发布全域紧急通知；[[光息]] 以光源为媒介进行影像通讯。
- [[堇粉]] 与 [[心音]]：日常照明与心灵联结；[[心音刀]] 可暂时屏蔽 [[心音]]。

## 七、核心矛盾与叙事功能

1. **保密是保护还是枷锁**：[[CEC]] 认为保密保护内界存续；[[新兴派]] 认为保密是枷锁；[[卯]] 认为旧秩序必须被主动推倒。
2. **知情权**：[[CEC]] 的 [[高层/中层/普通民众知情分级]]；[[渡]] 的身世；[[内界]] 对人类隐瞒真相。
3. **科技与异能**：[[BSA]] 的 [[反制异能技术]]；[[洁·欧列特]] 的 [[雷麟之网]]；[[新兴派]] 的 [[科技+异能融合]]。
4. **秩序与自由**：[[CEC]] 的 [[制度性瘫痪]]；[[卯]] 的 [[第三窟]]；[[法登]] 的 [[中间派独立势力]]；[[林默]] 的 [[人类要成为棋手]]。
5. **历史无断层**：本纪元坚持 [[无精灵隐世]]、[[无核心人物失忆]]、[[无狗血桥段]]，保证 16—21 世纪历史连贯。
