# CEC

**CEC**（Confidentiality Executive Committee，[[内界保密性执行委员会]]，即 [[密保会]]）前身为 1531 年成立的 [[内保会]]，是 [[保密纪元]] 的最高秩序机构，负责维系 [[内界族群秩序]]、调解 [[阵营冲突]]、保管并执行《[[1531保密公约]]》、管控 [[觉醒者曝光事件]]、掩盖 [[异能痕迹]]，并在后期与 [[BSA]] 官方建交、共建新时代共存秩序。

## 一、机构溯源

1. **前身**：1531 年 [[内保会]] 成立；[[群岛事件]] 与 [[弑魔潮]] 迫使 [[四大主流阵营]] 联合 [[小众势力]]，召开 [[保密和会]]，签署《[[1531保密公约]]》。
2. **保密纪元**：[[内保会]] 统筹全局，后正式定名 [[CEC]]；成为 [[内界传统最高秩序机构]]、[[旧保密规则守护者]]、[[主流族群联合统治核心]]。
3. **觉醒纪元**：[[保密规则崩塌]] 后，[[CEC]] 识破 [[BSA]] 伪装，双方被迫正式建交；[[CEC]] 推动转型，协调 [[内界]] 与 [[人类]] 建交。
4. **关联节点**：[[内保会]]、[[密保会]]、[[1531保密公约]]、[[保密和会]]、[[四大主流阵营]]、[[BSA建交]]、[[CEC转型]]。

## 二、顶层领导层枝干

[[CEC]] 顶层由 [[四大主流族群高层]] 与 [[老牌小众种族族长]] 共同组成：

- [[精灵族长老团]]：[[卯]]、[[云莲]] 为核心；连接 [[精灵六阁]]、[[宗氏]]、[[古典派]]。
- [[神嗣族王室/元老会]]：连接 [[十三神明]]、[[原初天使]]、[[高阶天使]]、[[次代天使]]、[[神嗣教会制]]。
- [[使徒族群首席祭司/高层议会]]：连接 [[法师部]]、[[首席领读]]、[[学术领读]]、[[甘图·范]]、[[斐琏·范]]。
- [[幻影族群群居领主、资深元老]]：连接 [[幻影联盟]]、[[幻影联邦制]]、[[克鲁伯·惠特尼斯]]、[[锚定]]。
- [[归附的小众种族代表、古老部族首领]]：连接 [[小众种族]]、[[散落部族]]、[[龙港]]、[[灰色独立势力]]。

[[CEC]] 存在军权，但由 [[会议]] 调动；在 [[动员令]] 下可直接听命于 [[主席（卯）]]。下设多个部门负责 [[行政]]、[[民政]]、[[治安]] 等；[[有关部门]] 拥有军权代行权，如 [[治安司]]、[[应急部]]。

## 三、内部派系枝干

1. [[CEC保守派]]：固守隐世、严控人类接触、维护旧公约；以 [[精灵旧长老]]、[[神嗣老贵族]] 为主；连接 [[古典派]]、[[1531保密公约]]、[[不可显露于世]]。
2. [[CEC改革派]]：认同适度开放、愿意和人类有限建交、接受 [[科技与异能共存]]；以 [[新兴派]] 和部分 [[使徒]] 为主；连接 [[科技冲击]]、[[BSA建交]]、[[觉醒纪元]]。
3. [[CEC中间派]]：中立调停、维持势力平衡、不极端站队；关键时刻左右决策；以 [[精灵族部分长老]] 和 [[小众种族]] 为代表；连接 [[卯]] 的 [[程序正义]] 与 [[议程规则]]。

## 四、层级管控体系

[[CEC]] 对内界民众实行 [[知情分级]]：

- **高层**：全知历史、全知 [[BSA]] 存在、全知 [[世界真相]]；连接 [[卯]]、[[云莲]]、[[四大族群高层]]。
- **中层**：知晓部分秘辛、了解基本 [[人类博弈]] 与 [[保密规则]]；连接 [[CEC中层官员]]、[[治安司]]、[[应急部]]。
- **普通内界民众**：只知基础族群常识，不接触深层历史与人类机密，避免无序冲突；连接 [[内界民众]]、[[龙港流民]]、[[小众种族]]。

## 五、职能枝干

1. 维系 [[内界族群秩序]]、调解 [[阵营冲突]]。
2. 保管并执行《[[1531保密公约]]》。
3. 管控 [[觉醒者曝光事件]]、掩盖 [[异能痕迹]]。
4. 后期与 [[BSA]] 官方建交、共建 [[新时代共存秩序]]。
5. 维护 [[CEC官网]]、[[公共TPD]]、[[谕]] 与 [[光息]] 等制度基础设施。
6. 通过 [[治安司]]、[[应急部]] 行使 [[军权代行权]]。
7. 通过 [[议程规则]] 与 [[程序正义]] 影响 [[武装镇压]] 决议；[[卯]] 利用该机制拖延对 [[新兴派]] 与 [[BSA]] 的镇压。

## 六、权力特征与核心痛点

[[CEC]] 采用 [[类安理会模式]]：多方势力投票决议，军权名义上属于会议，代行权下放 [[治安司]] 与 [[应急部]]。其核心痛点是 [[制度性瘫痪]]：当危机爆发时，各方为了己方利益互相扯皮，导致 [[CEC]] 武力干涉的决议往往延误。[[卯]] 作为主席，利用议程规则即可轻易拖延武装镇压，为 [[新兴派]] 与 [[BSA]] 的接触创造窗口。该痛点连接 [[内界事变]]、[[科技冲击与派系分裂]]、[[保密规则崩塌]]、[[卯的第三窟]]、[[十年之内事变]]。

## 七、关键人物与关联节点

- [[卯]]：[[CEC]] 创始元老之一、[[主席]]、[[精灵族核心长老]]、[[古典派领袖]]；利用 [[CEC]] 议程规则拖延镇压，暗中推动 [[十年之内事变]]。
- [[云莲]]：[[CEC]] 高层、[[精灵族资深长老]]、[[古典派核心]]；辅佐 [[卯]] 维系秩序。
- [[甘图·范]]：[[法师部首席领读]]；在 [[CEC]] 体系内为 [[法师部]] 争取生存利益；末期顺水推舟倒向 [[BSA]]。
- [[斐琏·范]]：[[法师部学术领读]]；从 [[CEC]] 授权研究 [[觉醒]] 到质疑 [[保密体系]]，成为 [[风暴的引信]]。
- [[林默]]：[[BSA第五任局长]]；[[CEC]] 的对手与建交对象；推动 [[人类成为棋手]]。
- [[何丁晖]]：[[新兴派首席]]；[[CEC]] 重点提防对象；与 [[法登]] 进行 [[契约会谈]]。
- [[法登·瑞文杰]]：[[CEC]] 重点提防对象；被 [[卯]] 刻意放缓清剿的“变量”。
- [[渡]]：[[CEC软禁学者]]；连接 [[CEC]] 内部研究与 [[觉醒纪元更替]]。
