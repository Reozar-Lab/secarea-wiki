# 龙港

**龙港**（原 [[灰域]]）是远古 [[觉醒者]] 遗留的 [[无主亚空间]]，[[人类]] 无法感知，不在现实地理版图内。它鱼龙混杂，汇聚 [[地下帮派]]、[[异能黑市]]、[[情报商人]]、[[流浪觉醒者]]、[[小众流民]]、[[CEC探子]] 与 [[BSA外围特工]]，自带 [[暗网体系]]，是全势力交汇、交易、密谋与群像角色游走的核心舞台。

## 一、地域定位

1. **空间定位**：[[无主亚空间]]；[[人类]] 无法感知；不在现实地理版图内；连接 [[TPD]]、[[公共TPD]]、[[领域]]、[[传送法阵]]。
2. **生态定位**：[[鱼龙混杂]]；[[地下帮派]]、[[地下组织]]、[[异能黑市]]、[[情报交易]]、[[违规交易]]；连接 [[龙港地下帮派]]、[[异能黑市]]、[[情报商人]]、[[流浪觉醒者]]、[[小众流民]]。
3. **叙事定位**：完美作为 [[群像人物]] 交汇舞台；[[法登]] 在龙港、各方势力间游走，自然铺开 [[世界观]]、[[地域]]、[[机构]]、[[族群格局]]，再逐步铺开其他群像人物支线。
4. **势力定位**：[[CEC]]、[[BSA]]、[[新兴派]]、[[古典派]]、[[幻影联盟]]、[[法师部]]、[[精灵族]]、[[小众种族]] 的暗线在此交汇；连接 [[CEC探子]]、[[BSA外围特工]]、[[新兴派渗透者]]、[[情报贩子]]。

## 二、舞台枝干

### 1. [[龙港地下帮派]]

灰色秩序的实际维持者之一；连接 [[地下组织]]、[[帮派火并]]、[[保护费]]、[[灰色交易]]、[[龙港治安]]、[[CEC治安司]]、[[BSA外围特工]]。

### 2. [[异能黑市]]

违禁法器、实验资料与情报的交易网络；连接 [[违禁法器]]、[[实验资料]]、[[觉醒实验]]、[[渡的实验体身份]]、[[BSA反制技术]]、[[CEC管控]]、[[契约信]]、[[领域]]。

### 3. [[龙港情报网络]]

连接 [[内界]]、[[人类]] 与各派系的暗线；连接 [[情报商人]]、[[情报贩子]]、[[CEC探子]]、[[BSA外围特工]]、[[林默的结派之路]]、[[何丁晖]]、[[法登]]。

### 4. [[法登的基金会]]

[[法登]] 创立的 [[独立基金会]]，龙港核心中立势力；连接 [[法登·瑞文杰]]、[[克鲁伯·惠特尼斯]]、[[洁·欧列特]]、[[雷麟之网]]、[[基金会风波]]、[[渡失踪]]、[[中间派独立势力]]。

### 5. [[幻影族聚居地]]

[[克鲁伯·惠特尼斯]] 早年在龙港建立的 [[幻影族小型聚居地]]；连接 [[幻影联盟]]、[[锚定]]、[[群居传统]]、[[CEC群居限制]]、[[基金会防御堡垒]]。

### 6. [[雷麟之网]]

[[洁·欧列特]] 为 [[基金会]] 搭建的独立情报与通讯网络；连接 [[洁·欧列特]]、[[麒麟族]]、[[雷电与电磁能量]]、[[网络攻防]]、[[情报预判]]、[[安保系统破解]]、[[BSA明面全球联络网]]。

### 7. [[龙港暗网体系]]

连接 [[CEC官网]]、[[谕]]、[[光息]]、[[TPD]]、[[公共TPD]]、[[情报交易]]、[[匿名通讯]]、[[灰色交易]]。

## 三、势力交汇枝干

- [[CEC]]：通过 [[CEC探子]]、[[治安司]]、[[应急部]] 监控龙港；[[公共TPD]] 站点可能设于龙港边缘。
- [[BSA]]：通过 [[BSA外围特工]]、[[明面全球联络网]]、[[外围执行层]] 在龙港活动；[[林默]] 可能在此与 [[何丁晖]]、[[法登]] 会晤。
- [[新兴派]]：[[何丁晖]] 与 [[法登]] 的 [[契约会谈]] 可能涉及龙港；[[新兴派]] 渗透 [[龙港部分势力]]。
- [[古典派]]：[[卯]] 通过 [[CEC]] 议程规则与 [[十年之内事变]] 影响龙港暗线；[[法登]] 被视为“变量”。
- [[幻影联盟]]：[[克鲁伯·惠特尼斯]] 的 [[幻影族聚居地]] 是 [[幻影本族]] 与 [[附属种族]] 的节点。
- [[法师部]]：[[甘图·范]] 与 [[斐琏·范]] 的 [[二元权力结构]] 可能通过 [[龙港]] 获取 [[实验资料]] 与 [[法器]]。
- [[精灵族]]：[[卯]]、[[云莲]]、[[云莫]] 与 [[精灵六阁]] 的决策可能影响龙港势力平衡。
- [[小众种族]]：[[散落部族]]、[[流浪觉醒者]]、[[无归属游离势力]]、[[天使分支派系]]、[[异类混血族群]]、[[异能变异个体集群]] 在龙港盘踞灰色地带或隐居自保。

## 四、人物节点枝干

- [[法登·瑞文杰]]：[[独立基金会]] 创立者、[[流浪觉醒者领袖]]、[[龙港核心中立势力]] 掌舵人；在龙港底层摸爬滚打，见证 [[密保会]] 腐朽与 [[族群共存]] 可能性。
- [[渡]]：[[法登]] 养女；在 [[基金会风波]] 中被 [[CEC反对势力]] 掳走，对外宣称失踪；连接 [[CEC软禁]]、[[觉醒纪元更替]]、[[斐琏·范]]。
- [[克鲁伯·惠特尼斯]]：[[幻影族高层]]；在龙港建立 [[幻影族聚居地]]；基金会风波中用 [[锚定]] 构筑防御堡垒。
- [[洁·欧列特]]：[[麒麟族（原神嗣）]]；为基金会搭建 [[雷麟之网]]；负责 [[网络攻防]]、[[情报预判]]、[[安保系统破解]]。
- [[何丁晖]]：[[新兴派首席]]；与 [[法登]] 进行 [[契约会谈]]；可能通过龙港暗线与 [[林默]] 接触。
- [[林默]]：[[BSA第五任局长]]；通过 [[BSA外围特工]] 与 [[明面全球联络网]] 在龙港布局；[[人类成为棋手]]。
- [[张舟]] 与 [[河萍]]：[[渡]] 亲生父母；[[内保会]] 成员；参与 [[第一次公社]] 与 [[后天觉醒实验]]；其 [[契约信]] 与 [[邀请函]] 可能经龙港流转。
- [[云莫]]：[[卯]] 的部下；可能通过龙港暗线传递 [[精灵六阁]] 信息。
- [[禾]]：[[卯]] 的师傅；其 [[狡兔三窟]] 教诲通过 [[卯]] 影响龙港暗线。

## 五、规则与物品枝干

- [[TPD]]：龙港内通行依赖 [[TPD]]；[[公共TPD]] 站点可能伪装为电话亭、公厕门；[[领域]] 防止 [[TPD]] 随意闯入。
- [[契约信]]：龙港交易常用 [[契约信]]；[[法登]] 与 [[何丁晖]] 的 [[契约会谈]] 使用该体系；[[生死契]] 法律不予认可与保护。
- [[异能黑市]]：交易 [[违禁法器]]、[[实验资料]]、[[情报]]；连接 [[堇粉]]、[[心音刀]]、[[谕笔]]、[[光息棒]]、[[TPD家用型传送家具]]。
- [[CEC官网]]：龙港暗网可能通过 [[CEC官网]] 的 [[HTTP代理]]、[[VPN]]、[[DNS]] 连接 [[觉醒者自建服务器]]；部分功能收费。
- [[谕]] 与 [[光息]]：龙港情报网络常用 [[谕]] 与 [[光息]]；支持匿名、拒收、屏蔽、白名单、群聊。
- [[堇粉]]：龙港住宅、店铺、黑市空间常用 [[堇粉]] 照明；高端堇粉可调亮度、色彩、区域光效。
- [[心音]]：龙港亲密关系、养父母与养子女、伴侣之间可能建立 [[心音]]；[[心音刀]] 可暂时屏蔽。

## 六、核心矛盾与叙事功能

1. **三不管与灰色秩序**：[[龙港]] 无统一秩序；[[地下帮派]]、[[异能黑市]]、[[情报商人]] 形成 [[灰色秩序]]；[[CEC]] 与 [[BSA]] 在此暗线博弈。
2. **群像交汇**：[[法登]]、[[渡]]、[[克鲁伯]]、[[洁]]、[[何丁晖]]、[[林默]]、[[张舟]]、[[河萍]]、[[云莫]] 等角色在龙港交汇；[[基金会风波]]、[[渡失踪]]、[[契约会谈]]、[[林默的结派之路]] 在此展开。
3. **中间派独立势力**：[[法登]] 的 [[基金会]] 是 [[反霸权中间派]] 代表；既不依附 [[CEC]]，也不完全认同 [[新兴派]]；连接 [[中间派独立势力]]、[[自由共存]]、[[底层觉醒者]]、[[小众族群]]。
4. **秘密与真相**：[[渡]] 的身世、[[实验体身份]]、[[CEC软禁]]、[[BSA反制技术]]、[[卯的第三窟]] 在龙港暗线中交织。
5. **科技与异能**：[[洁·欧列特]] 的 [[雷麟之网]]、[[BSA]] 的 [[反制异能技术]]、[[新兴派]] 的 [[科技+异能融合]]、[[异能黑市]] 的 [[违禁法器]] 在龙港并存。
